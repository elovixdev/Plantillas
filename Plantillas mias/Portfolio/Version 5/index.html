Quién te va a estar escribiendo el código

Trabajo con HTML, CSS y JavaScript puro: sin plantillas genéricas, sin builders que atan tu sitio a una plataforma. Cada página la pienso y la escribo para el negocio que la necesita.

Uso Git y GitHub para versionar cada proyecto, así que si mañana necesitás un cambio, hay un historial prolijo de todo lo que se hizo —y quién lo hizo. Trabajo desde VS Code, con foco en código limpio y sitios livianos que cargan rápido.

"No vendo plantillas. Escribo la página que tu negocio necesita, para que quien la visite haga lo que vos necesitás que haga."

Si vendés cursos, productos o servicios y necesitás una página que explique bien la propuesta y lleve a la acción —comprar, inscribirse, escribirte— es exactamente el tipo de proyecto en el que me metí más de una vez.

Trabajo freelance, coordino todo por mensaje o videollamada, y entrego el sitio listo para publicarse, con el código disponible en un repositorio propio.

Cómo trabajamos

De la idea a la página publicada

01

Charlamos sobre tu proyecto

Me contás qué necesitás vender o mostrar, quién es tu cliente y qué acción querés que tome al entrar al sitio.

02

Te propongo una estructura

Defino las secciones, el recorrido y el estilo visual antes de escribir una sola línea de código, así ambos sabemos hacia dónde vamos.

03

Desarrollo el sitio

Escribo el HTML, CSS y JavaScript, versionando cada avance en GitHub. Te muestro avances parciales para ajustar sobre la marcha.

04

Entrega y acompañamiento

Publicamos el sitio y te dejo el código organizado. Si necesitás cambios más adelante, ya conozco tu proyecto de memoria.
